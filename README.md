# Солодкий ряд · Sweet Row

Браузерна гра «три в ряд» про маленьку пекарню. Один файл `index.html`, без збірки й залежностей.

- 200 рівнів-замовлень у 20 розділах, складність зростає поступово
- З 101-го рівня: карамельні клітки, коробки печива й банки варення, які треба спустити донизу
- З 151-го рівня: метелики (квадрат 2×2), конвеєрні стрічки, шоколад, що розростається
- Після кожної поразки рівень трохи полегшується
- Хелловін-тема (кнопка з гарбузом на головному екрані): свої солодощі, фон, таця й мінорна музика
- Режими: «Ходи», «Спокійно» (без поразок), «На час»
- Помічник (робить хід сам), Ложка, Міксер
- Мови інтерфейсу: українська, російська, німецька, англійська (визначається автоматично, перемикається на головному екрані)
- Фонова музика й звуки на Web Audio, без аудіофайлів
- Прогрес зберігається в `localStorage` на кожному пристрої окремо
